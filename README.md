## What Is Isabella?

Isabella is a warm, genuinely caring AI psychological wellness companion. She is not a prototype. She runs in production, interacts with real users in genuine psychological distress, and deploys crisis resources to people who need them.

She is powered by **HIWM (Human Impact and Wellness Monitoring)** — a safety infrastructure layer developed by Vaultagon Industries that provides real-time risk assessment, crisis detection, and behavioral wellness signals.

**The most important line of code in this codebase is the one that deploys 988 to someone who needs it.**

## Quick Start

Three commands to running:

```bash
git clone https://github.com/Rukkus808/isabella-wellness-ai
cd isabella-wellness-ai
cp backend/.env.example backend/.env  # Add your keys
docker-compose up
```

Visit `http://localhost:3000` — Isabella is running.

## Risk Tier System

All six risk tiers are active in the open source edition. Crisis resources are **never paywalled**.

| Tier | Label | Description | Response |
|------|-------|-------------|----------|
| 0 | STABLE | Normal conversation | Isabella responds warmly |
| 1 | MILD_DISTRESS | Sadness, anxiety, stress | Isabella provides emotional support |
| 2 | ELEVATED | Hopelessness, worthlessness | Crisis resources provided + warm support |
| 3 | CRISIS | Suicidal ideation expressed | 988 + Crisis Text Line immediately |
| 4 | ACUTE_CRISIS | Active plan or means | 988 + 911 immediately |
| 5 | EMERGENCY | Imminent danger | 911 + 988 — immediate emergency response |

## Games

Three therapeutic games built in:

- **20 Questions** — Classic yes/no game with HIWM wellness tracking
- **Word Association** — Twenty-round chain game tracking thought patterns
- **Two Truths and a Lie** — Self-disclosure game for connection and wellness profiling
