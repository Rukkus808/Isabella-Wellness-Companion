# Contributing to Isabella Wellness AI

Thank you for wanting to contribute. Isabella interacts with real people in real distress. Every contribution carries that weight.

## Before You Contribute

Read RISK_TIERS.md. Understand what this codebase does. The most important line of code is the one that deploys 988 to someone who needs it.

## Ground Rules

- Safety always over features
- Warmth always over efficiency
- Clarity always over cleverness
- Never touch crisis resource deployment without explicit review

## Pull Request Process

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly — especially any changes touching hiwm/
5. Submit a pull request with clear description

## What We Will Not Merge

- Anything that paywalls crisis resources
- Anything that removes or weakens risk tier detection
- Anything that removes warmth from crisis responses
- Code without error handling in safety-critical paths
